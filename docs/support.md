# DesignSphere Support

DesignSphere is an Apple Vision Pro interior-design application maintained by
the DesignSphere project team.

## Contact support

Use the [DesignSphere issue tracker](https://github.com/JaimieMarch/DesignSphere/issues/new)
to report a problem or ask a support question. Existing reports are available
on the [known-issues page](https://github.com/JaimieMarch/DesignSphere/issues).

Include:

- the DesignSphere app version and build number;
- the visionOS version;
- what you expected to happen;
- what actually happened; and
- concise steps that reproduce the problem.

GitHub issues are public. Do **not** attach saved projects, room scans, backup
files, imported private models, screenshots containing personal information, or
other sensitive content. Support is provided on a best-effort basis.

## Common questions

### Why is the catalog empty?

The remote catalog requires a network connection on first use. Check the
connection and reopen the app. After a successful load, the last manifest can
remain available offline.

### Why does a model need to download again?

Downloaded models and thumbnails are cache data. visionOS may remove cache data
when it needs storage space.

### Which model files can I import?

The current app accepts valid USDZ files up to 150 MB. Other model formats are
not supported.

### How do I remove my data?

Open **Settings > Manage Local Data**. Projects, imports, anchors, favorites,
and Labs preferences can be removed separately.

### How do backups work?

Open **Settings > Create Backup**, select the categories to include, and choose
a save location. Use **Import Backup** to restore one. Store backups carefully
because they may contain projects and imported models.

## Privacy
