# Design Sphere App 
DesignSphere is an interior design app built for the Apple Vision Pro. It allows users to create and customize spaces in real time within their actual rooms. The app eliminates guesswork in furniture fit, layout planning, and design decisions by letting users place true-to-scale 3D furniture models directly into their environment via the Vision Pro.  Designed for both students and professionals, DesignSphere provides tools to plan, visualize, and test interior layouts efficiently, making spatial computing practical and accessible for everyday design.

## Features
- Floating Screen navigation 
- Model library with favoriting, previews, 3D Model thumbnails
- Model editing tools (scale, rotate, position, texture, color)
- Room Saving and Loading
- Future Features:
  - Measurement tools (Ruler and Room Dimensions) 
  - Focus Modes
  - AI Assistant

## Requirements
- visionOS 26.0+
- Mac with Apple Silicon (M1+)
- Xcode with visionOS support
- SwiftUI, RealityKit, ARKit

## Running the App
1. Open the project in Xcode  
2. Select a Vision Pro simulator or device  
3. Build + run
