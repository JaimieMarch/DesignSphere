# DesignSphere

**See Your Vision. From Within.**

DesignSphere is an interior-design application for Apple Vision Pro. Place
furniture and décor at true scale in your own space, adjust and measure it, and
save room layouts to return to later.

## Privacy and support

- [Privacy Policy](privacy-policy.md) — what the app stores on device, what
  leaves the device, and how to remove local data.
- [Support](support.md) — how to report a problem, and answers to common
  questions.

## About the app

- Designed for visionOS; requires a network connection the first time the
  furniture catalog loads.
- No accounts, advertising, subscriptions, or in-app purchases.
- Projects, imported models, and spatial data stay on the device unless you
  explicitly export a backup.

The source code is available on
[GitHub](https://github.com/JaimieMarch/DesignSphere).
